Project: Resource Allocation Optimization (MIP)

Goal: To determine the optimal production mix for a factory to maximize total profit while adhering to limited resource constraints (labor and machine time).

Methodology:

This problem was formulated as a Mixed-Integer Program (MIP), ensuring that production quantities (the decision variables) are non-negative integers.

Modeling Language: Python (using the PuLP library)

Solver Used: CBC (Coin-or-Cut Branch and Cut, an open-source, industry-standard solver)

Key Outcome:

The optimization model calculated the exact quantity for each product that utilizes the available labor and machine hours most efficiently, resulting in the highest achievable profit for the given constraints. This demonstrates proficiency in translating business problems into executable mathematical code.
